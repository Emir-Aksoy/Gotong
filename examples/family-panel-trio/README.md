# family-panel-trio — 家庭面板三件套(SDUI 形态预设包)

> 画廊第一个**panel-only** 模板:零 agent、零工作流、零知识库,装的是三张
> 「成员面板长什么样」的**形态**(SDUI-M3)。同一个 hub、同一套数据,不同的
> 家人看到不同的第一屏。

## 三张形态

| id | 给谁 | 第一屏是什么 |
|---|---|---|
| `father-farm-care` | 种地的父亲 | 三天天气 + 农事周历 + 农活清单 + 农事心得卡 + 问阿同 |
| `mother-local-life` | 操持生活的母亲 | 本地新闻晨报流 + 今日天气 + 日程一览 + 阿同对话 + 三个一键动作 |
| `family-ops-board` | 当 operator 的家人 | hub 状态 + 待批收件箱 + 用量周图 + 日程 + 对话 + 快捷入口 |

## 装法

1. 管理面板 → 模板画廊 → 「家庭面板三件套」一键安装。三张形态落进
   `<space>/butler/ui/library/`(hub 的形态库),**不会**改动任何人的当前面板。
2. 成员打开「面板」标签,底部「面板形态」区能看到三张卡,点「换上」即切换;
   随时「恢复默认」退回出厂形态。
3. owner 也可以在同一区替某位家人直接装上(给不会自己动手的长辈);对方
   随时可自己换掉——owner 装的只是初始形态,不是锁定。

## 边界(诚实模式)

- **形态 ≠ 权限**:面板只是排布。组件内容全部来自 hub 既有成员向 API,
  该看不到的数据换什么形态也看不到;审批收件箱是渲染器**保留区**,任何
  形态都盖不掉待批徽章(「编排 ≠ 伪装」)。
- **零前置**:装形态本身不需要任何 key / 连接器。绑 `connector:` 数据源的
  组件(天气 / 本地新闻 / 农事日历)在 hub 挂了同名 MCP 连接器之前如实显示
  「未接入」,面板其余部分照常工作。
- **file-first**:成员当前形态存 `<space>/butler/ui/user/<userId>/panel.json`,
  删掉该文件 = 回到默认形态;复制 `.gotong/` 目录 = 形态跟着搬家。
