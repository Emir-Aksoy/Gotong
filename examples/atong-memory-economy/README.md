# 记忆经济 capstone —— 一万轮之后,记忆还是那个记忆

```bash
pnpm demo:memory-economy
```

零 API key、固定钟、确定性。**每一项都成立才退 0**,否则退 1 并列出没过的项。

记忆经济这条 track 有一句可证伪的话:**大小常量有界、跨店一次召回、用则存不用则忘**。
这个 demo 端到端地证它 —— 全程用 M1~M4 **真的导出的代码**(一行都不重写),用它们自己
立的尺量。

---

## 剧本

一万轮合成对话,四十件互不相干的事,**六成是复述**(常驻管家在 IM 上的真实形态)。
两条路跑**同一份剧本**(同一个种子),差别只有一处:

| | 写侧 | 逐出 |
|---|---|---|
| **今天** | 裸 `remember`,每一轮都落盘 | `enforceBudget`,只看重要度与新旧 |
| **记忆经济** | `rememberNovel`(M4 新颖门) | `enforceBudget` + 通了电的显著性(M3b) |

预算刻意收紧到 25 条左右 —— **一个装得下一切的预算量不出经济学**。

---

## 第一幕:一万轮之后,盘上还剩什么

```
今天       写入 10000 次 · 盘上 25 条 / 2979 字节 · 不同的事 10/40 · 每条携带 0.40 件事 · 召回 20 格里 9 件 · 一路逐出 9975 条
记忆经济   写入  2001 次 · 盘上 13 条 / 2894 字节 · 不同的事 13/40 · 每条携带 1.00 件事 · 召回 20 格里 13 件 · 一路逐出 1988 条
```

**先说清楚哪一条不算 M4 的功劳**:「字节 ≤ 预算」「条数是常量级」两条路都成立 ——
那是 `enforceBudget` 早就有的。M4 挣到的是密度:

- **写入放大 5 倍**:10000 次 → 2001 次。复述压根没落盘。
- **盘上零重复**:经济的 13 条正好是 13 件**不同的**事;今天的 25 条里只有 10 件,
  其余 15 条是同一句话的副本在占位。
- **召回名额**:一次 `recall(k=20)` 里,今天只够得着 9 件不同的事,经济够得着 13 件。

有一栏看着像退步,值得直说:**经济的条数更少(13 对 25)**。折叠会让存活的条目变胖
——它们多带了强化计数与边。这不是意外,M4 的字节账早就量过:折叠付**一次性常量**、
省**每次复述的线性项**,极短条目恰好复述两次时甚至小亏。要看的是密度那两栏。

还有一个数**如实报但不算成绩**:M3a 的记忆账在这个剧本里分不出两条路(都常年第 ④ 级)。
账读的是「这一 tick 攒了多少压力」,而 200 轮攒下的写入对 25 条的预算来说谁都超得远。
M4 减的是写入次数,不是「两次维护之间会不会超预算」。

## 第二幕:沉淀下来的东西,会不会挤掉跨店召回

拿第一幕**真的剩在盘上的**条目当干扰项(不是另编一批噪声),灌进一个七店俱全的成员
空间,用 M1 的整合尺量同样四个问题:

```
干净空间(3 条记忆,无沉淀)        总召回 91.7% · 单店 100.0%
今天沉淀的 25 条底下              总召回 66.7% · 单店   0.0%   ← 「我对什么过敏」答不出来了
记忆经济沉淀的 13 条底下          总召回 91.7% · 单店 100.0%
```

**这是整个 capstone 的正题**。今天那 25 条里的 15 条复述,把唯一那条过敏记忆挤出了
前五 —— 一个每天都在被问的问题,在一万轮闲聊之后**变成答不出来的**。这正是设计文档
第一节那句诊断的可证伪版本:「同一句话说十遍…它们十条都在占召回名额」。

排名如实说,不许拿「召回不降」当「毫发无损」讲:沉淀确实把单店那一例从第 1 挤到了
第 2(MRR 1.000 → 0.500)。召回守住了,排名有升有降。

## 第三幕:用则存不用则忘

两条**一模一样重要、一模一样新**的事实,差别只有用没用过:一条在头十天里被召回五次
(走真的 `reinforcedMeta`),一条从没被碰过。两个月后预算只装得下一条。

```
半衰期 30 天 · 强化权重 0.5
被召回 5 次的那条   显著性 2.166   ← 活下来
从没被碰过的那条    显著性 0.750   ← 凉下去
```

## 北极星

全程框架跑了 **0 个模型**。新颖门、记忆账、显著性、逐出、跨店扩散全是纯函数;唯一会
调模型的 6h 蒸馏链在这里根本没上场。凭证零、固定钟、可复现。

各里程碑在这份剧本里的位置:

| | 是什么 | 在哪一幕 |
|---|---|---|
| M1 | `scoreIntegration` 跨店整合尺 | 第二幕拿它量 |
| M2 | `buildMemoryNet` + `crossStoreRecall` | 第二幕一次召回走遍七个店 |
| M3 | `readLedger` 四级阶梯 + 通了电的 `effectiveSalience` | 第一幕的逐出、第三幕的存亡 |
| M4 | `rememberNovel` 写侧新颖门 | 第一幕把一万轮压成两千次写入 |
| M5 | 本篇 | 退出码就是判据 |
